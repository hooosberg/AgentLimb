UIXskills is a platform that bridges the gap between design and code using AI-native protocols.

## The Concept

Traditional design-to-code workflows are broken: designers create in Figma, developers interpret in code, and the translation loses fidelity. UIXskills introduces a protocol layer — structured JSON that both AI and humans can read.

- **AI → JSON → Whiteboard → SKILL → UI** — a pipeline from AI generation to rendered interface
- **Design guidelines** — codified design system rules that AI can follow
- **Multi-framework support** — React and SwiftUI skill libraries
- **Claude Code integration** — skills designed for AI-first development workflows

## The Ecosystem

UIXskills, DOMPrompter, and AgentLimb form a complementary ecosystem:

| Tool | What it does |
|---|---|
| **UIXskills** | Design protocol — what to build |
| **DOMPrompter** | Visual annotation — what to change |
| **AgentLimb** | Browser automation — how to operate |

All three share the same philosophy: local-first, AI-native, developer-focused.
