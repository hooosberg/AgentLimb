OpenAI and Google have both launched fully agentic coding tools, signaling that AI-powered development has moved from experiment to mainstream product category.

## OpenAI Codex

OpenAI's Codex is a cloud-based coding agent that can:
- Clone repositories and work on them autonomously
- Run tests, fix bugs, and submit PRs
- Operate in sandboxed environments

## Google Kiro

Kiro, from AWS, takes a different approach with spec-driven development:
- Write a specification document
- Kiro generates an implementation plan
- The agent implements, tests, and iterates

## What This Means

When OpenAI and Google enter a market with dedicated products, the category is validated. Independent tools like Cursor, Windsurf, and AgentLimb operate in a market that the biggest companies in tech believe is real and important.

For AgentLimb specifically: more coding agents means more potential users who need browser automation. Every one of these tools can connect to AgentLimb to extend their reach from code into the browser.
