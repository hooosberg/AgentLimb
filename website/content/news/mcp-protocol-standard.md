The Model Context Protocol (MCP), originally created by Anthropic, has been adopted by dozens of AI tools as the standard way to connect AI models to external services, databases, and automation tools.

## What is MCP?

MCP provides a standardized way for AI models to discover and use external tools. Instead of building custom integrations for each AI, tool creators implement MCP once and work everywhere.

## Who Uses MCP

- **Claude Code** — native MCP support
- **Cursor** — MCP tool integration
- **AgentLimb** — bridge speaks MCP natively with 8 standardized tools
- **Dozens of database, API, and automation tools**

## What This Means

For AgentLimb users: any AI tool that supports MCP can automatically connect to AgentLimb's bridge. No custom configuration. No adapters. The 8 tools are universally accessible.

The standardization of MCP is good for the ecosystem — it means your tool choices aren't locked in. Use Claude Code today, switch to Cursor tomorrow, and AgentLimb works with both.
