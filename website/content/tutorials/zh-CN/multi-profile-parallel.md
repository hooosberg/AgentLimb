## 这个功能做什么

AgentLimb v0.1.3 让你的 AI 同时驱动多个 Chrome Profile——并行执行，一条指令搞定。

如果你有三个 Twitter 账号、两个公司 Google Workspace 登录，或者一打测试 Profile，你不再需要把同一个任务跑三遍。一条指令同时到达所有打开的侧边栏。

每个 Profile：
- 在侧边栏标题显示**明确的身份标识**（例如 `Profile-a3f2`）
- 自动将 AI 操作**锁定到正确的 Chrome 窗口**
- 可以**单独挂起**（退出参与）而不影响其他 Profile
- 接收**完整的任务生命周期**——计划、步骤更新、以及最终的成功或失败结果

---

## 怎么设置

你不需要配置任何新东西。只要打开了多个侧边栏，多 Profile 行为就会自动生效。

**第一步——创建多个 Chrome Profile**

打开 Chrome → 点击右上角头像 → **添加** → 按需创建多个 Profile。每个 Profile 有独立的 Cookie、会话和登录状态。

**第二步——在每个 Profile 中打开侧边栏**

在每个 Chrome Profile 窗口中，点击 AgentLimb 图标或从扩展菜单打开侧边栏。你应该在每个面板的标题栏看到该 Profile 的身份标签。

**第三步——连接你的 AI**

从任意一个侧边栏复制接入提示词，粘贴给你的 AI 终端。Bridge 会自动发现所有已连接的 Profile。

搞定。你的 AI 现在已连接到所有打开的 Profile。

---

## 在所有 Profile 上运行任务

像平时一样给 AI 一条指令，例如：

> 发布"我们的新功能上线了——快来 agentlimb.com 看看"到 Twitter。

AI 会：
1. 声明 `task_plan`——所有侧边栏同时显示相同的步骤列表
2. 在每个活跃的 Profile 上并行执行任务
3. 所有活跃 Profile 完成后汇报 `task_complete`，并说明有哪些 Profile 被跳过（如果有挂起的话）

你可以在每个侧边栏独立看到执行进度。某个 Profile 可能比另一个先完成——它们不会互相等待。

---

## 窗口锁定：导航落到正确的地方

每个 Chrome Profile 可以同时打开多个窗口。没有窗口锁定，AI 的 `navigate` 指令可能落到错误的窗口里。

AgentLimb 会自动处理这个问题。当你打开侧边栏时，它会注册自己所在的 Chrome 窗口。该 Profile 的所有 `navigate` 调用都会精准定向到这个窗口——而不是 Chrome 在某个时刻认为"活跃"的那个窗口。

如果你关掉这个窗口，在另一个窗口重新打开侧边栏，锁定会自动更新。AI 跟着你的注意力走。

---

## 挂起一个 Profile（选择退出）

有时候你想在三个 Profile 中的两个上跑任务，不是全部。

**方式一——关闭侧边栏。** 关闭的面板意味着"这个 Profile 不参与"。AI 会静默跳过它，并在最终摘要中说明。

**方式二——点击挂起按钮。** 面板内的挂起按钮可以让该 Profile 退出，而不用关闭面板。适合你想保留面板可见性但暂时排除它的情况。

无论哪种方式，AI 都不会因为某个 Profile 被挂起而宣告整体任务失败。它继续对剩余的活跃 Profile 执行。只有当*所有* Profile 都被挂起时，AI 才会宣告 `task_fail(no_active_profile)`。

**恢复：** 只需重新打开面板或点击恢复按钮。Bridge 在 300ms 内检测到变化，下次任务自动纳入该 Profile。

---

## 定向到特定 Profile

有些任务你想精确控制某一个 Profile，而不是广播给所有 Profile。

在指令中使用 `target` 参数：

> 仅使用 Profile-a3f2：更新 LinkedIn 个人简介。

AI 将这个标签传给 Bridge，Bridge 将工具调用专门路由到该 Profile。其他 Profile 不受影响。

每个 Profile 的标签显示在其侧边栏的标题栏中。

## 一个实际例子

你的产品在三个 Chrome Profile 上分别有 X、微博和 Threads 的账号。

**之前的工作流：** 手动切换 Profile，跑三次发帖任务。

**使用多账号并行控制：**

1. 打开全部三个 Profile，在每个里面打开侧边栏
2. 给 AI 一条指令："把今天的构建进度发布到所有账号"
3. 三个侧边栏同时显示计划，三个 Profile 并行执行
4. 总耗时约等于跑一次的时间

如果某个账号被限流或挂起，那个 Profile 会被跳过。其他两个照常完成。最终摘要告诉你每个 Profile 的具体情况。

## 总结

| | v0.1.3 之前 | v0.1.3 |
|---|---|---|
| 在 3 个 Profile 上执行 | 3 次独立任务 | 1 条指令 |
| Profile 身份 | 无——AI 自行猜测 | 面板标题显示明确标签 |
| 窗口定向 | 跨窗口不可靠 | 自动锁定到正确窗口 |
| 排除某个 Profile | 无机制 | 关闭面板或点击挂起 |
| 任务结果 | 每次跑一个结果 | 单次汇报包含每个 Profile 的状态 |

多账号并行控制与肌肉记忆结合时效果最强——AI 已经知道每个网站的选择器，每个 Profile 的任务都以完整的热启动速度运行。
