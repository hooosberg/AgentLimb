## 이 기능이 하는 일

AgentLimb v0.1.3은 AI가 여러 Chrome 프로필을 동시에 구동할 수 있게 합니다 — 병렬로, 하나의 명령으로.

Twitter 계정 3개, 회사 Google Workspace 로그인 2개, 또는 수십 개의 테스트 프로필이 있다면, 같은 작업을 3번 반복할 필요가 없습니다. 하나의 명령이 열려 있는 모든 사이드 패널에 동시에 전달됩니다.

각 프로필은:
- 사이드 패널 헤더에 **명시적인 신원**을 표시 (예: `Profile-a3f2`)
- AI 작업을 **올바른 Chrome 창**에 자동으로 잠금
- 다른 프로필을 중단하지 않고 **독립적으로 일시정지** 가능
- **완전한 작업 생명주기** — 계획, 단계 업데이트, 최종 성공/실패 결과 수신

---

## 설정 방법

새로 구성할 것이 없습니다. 여러 사이드 패널이 열려 있는 한 멀티 프로필 동작은 자동입니다.

**1단계 — 여러 Chrome 프로필 생성**

Chrome 열기 → 프로필 아바타 클릭 → **추가** → 필요한 만큼 프로필 생성. 각 프로필은 자체 쿠키, 세션, 로그인 상태를 갖습니다.

**2단계 — 각 프로필에서 사이드 패널 열기**

각 Chrome 프로필 창에서 AgentLimb 아이콘을 클릭하거나 확장 프로그램 메뉴에서 사이드 패널을 엽니다. 각 패널의 헤더에 프로필의 신원 레이블이 표시됩니다.

**3단계 — AI 연결**

어느 사이드 패널에서나 온보드 프롬프트를 복사하여 AI 터미널에 붙여넣습니다. Bridge가 연결된 모든 프로필을 자동으로 검색합니다.

끝입니다. AI가 이제 열려 있는 모든 프로필에 연결되었습니다.

---

## 모든 프로필에서 작업 실행

평소처럼 AI에 하나의 명령을 줍니다. 예:

> "새 기능이 출시되었습니다 — agentlimb.com에서 확인하세요"를 Twitter에 게시해주세요.

AI는 다음과 같이 동작합니다:
1. `task_plan` 선언 — 모든 사이드 패널이 동시에 같은 단계 목록 표시
2. 각 활성 프로필에서 병렬로 작업 실행
3. 모든 활성 프로필 완료 후 `task_complete` 보고, 일시정지된 프로필이 있으면 명시

각 사이드 패널에서 진행 상황을 독립적으로 확인할 수 있습니다. 하나가 다른 것보다 먼저 완료될 수 있습니다 — 서로 기다리지 않습니다.

---

## 윈도우 잠금: 탐색이 올바른 곳에 도달

각 Chrome 프로필은 여러 창을 열 수 있습니다. 윈도우 잠금 없이는 AI의 `navigate` 명령이 잘못된 창에 도달할 수 있습니다.

AgentLimb이 이를 자동으로 해결합니다. 사이드 패널을 열면 자신이 있는 Chrome 창을 등록합니다. 해당 프로필의 모든 `navigate` 호출은 Chrome이 그 순간 "활성"으로 판단하는 창이 아닌 그 특정 창을 대상으로 합니다.

창을 닫고 다른 창에서 사이드 패널을 다시 열면 잠금이 자동으로 업데이트됩니다. AI가 여러분의 집중을 따라갑니다.

---

## 프로필 일시정지 (선택 해제)

세 프로필 중 두 개에서만 작업을 실행하고 싶을 때가 있습니다.

**방법 1 — 사이드 패널 닫기.** 닫힌 패널은 "이 프로필은 참여하지 않음"을 의미합니다. AI는 조용히 건너뛰고 최종 요약에 보고합니다.

**방법 2 — 일시정지 버튼 클릭.** 패널 내의 일시정지 버튼은 패널을 닫지 않고 해당 프로필을 선택 해제합니다. 패널을 보이게 유지하되 일시적으로 제외하고 싶을 때 유용합니다.

어느 방법이든 AI는 일시정지된 프로필 때문에 전체 작업을 실패로 처리하지 않습니다. 나머지 활성 프로필로 계속 진행합니다. *모든* 프로필이 일시정지된 경우에만 AI가 `task_fail(no_active_profile)`을 선언합니다.

**재개:** 패널을 다시 열거나 재개 버튼을 클릭하면 됩니다. Bridge는 300ms 이내에 변화를 감지하고 다음 작업에 자동으로 해당 프로필을 포함합니다.

---

## 특정 프로필 지정

모든 프로필에 브로드캐스트하는 대신 하나의 프로필을 정확하게 제어하고 싶을 때가 있습니다.

명령에 `target` 파라미터를 사용하세요:

> Profile-a3f2만 사용하여: LinkedIn 소개를 업데이트해주세요.

AI는 이 레이블을 Bridge에 전달하고, Bridge는 해당 프로필에만 독점적으로 도구 호출을 라우팅합니다. 다른 프로필은 영향받지 않습니다.

각 프로필의 레이블은 사이드 패널 헤더에 표시되어 있습니다.

## 실용적인 예시

X, 웨이보, Threads 계정을 세 개의 Chrome 프로필로 관리한다고 가정합니다.

**이전 워크플로우:** 프로필을 수동으로 전환하면서 게시 작업을 3번 실행.

**멀티 프로필 병렬 제어 사용:**

1. 세 프로필 모두 열고 각각에 사이드 패널 열기
2. AI에 하나의 명령: "오늘의 빌드 업데이트를 모든 계정에 게시해줘"
3. 세 사이드 패널이 동시에 계획 표시; 세 프로필이 병렬 실행
4. 한 번 실행하는 것과 거의 같은 시간에 완료

계정 하나가 속도 제한이나 일시정지가 된 경우 해당 프로필은 건너뜁니다. 다른 두 개는 정상적으로 완료됩니다. 최종 요약에 각 프로필의 자세한 상황이 보고됩니다.
