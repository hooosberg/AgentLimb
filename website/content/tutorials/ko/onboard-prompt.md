## 프롬프트란

프롬프트는 AI에게 AgentLimb에 대해 필요한 모든 것을 알려주는 텍스트입니다. 컴퓨터에서 실행 중인 브리지에 연결하는 방법, 사용 가능한 도구, 바탕화면 폴더에 이미 저장된 사이트 기억 등.

한 번 복사해서 AI에 붙여넣으면 설정 완료입니다. 설정 파일도, API 키도, AI 도구에서 추가 설치도 필요하지 않습니다.

---

## 가져오는 방법

Chrome의 AgentLimb 사이드 패널을 열고 **"프롬프트 복사"** 버튼을 클릭합니다. 프롬프트가 클립보드에 복사됩니다.

이 버튼을 클릭할 때마다 최신 프롬프트가 생성됩니다. 현재 연결 상태와 AI가 이미 학습한 사이트 정보가 포함됩니다.

---

## 사용 방법

AI 도구에서 새 세션을 시작할 때 프롬프트를 붙여넣습니다. AI가 읽으면 자동으로 브리지에 연결되어 브라우저 작업을 받을 준비가 됩니다.

그게 전부입니다.

---

## 모든 AI 도구 지원

- **Claude Code** — 세션 시작 시 붙여넣으면 Claude가 연결 정보를 읽고 자동 설정합니다.
- **Codex** — 붙여넣으면 연결되어 작업을 시작합니다.
- **Cursor, Windsurf, Trae** — 채팅 창에 붙여넣습니다. 추가 설정 없이 작동합니다.
- **로컬 AI 모델** — 도구 호출을 지원하는 모델이라면 사용 가능합니다.

지시를 따르고 외부 도구를 사용할 수 있는 AI 도구라면 AgentLimb와 함께 작동합니다.

---

## 붙여넣은 후 작업 추가 가능

프롬프트를 붙여넣은 후 바로 원하는 것을 말할 수 있습니다:

> *"오늘의 제품 업데이트를 Reddit과 Hacker News에 올려주세요. 내용은: ……"*

AI는 AgentLimb 연결 정보와 지시를 결합하여 작업을 시작합니다.

---

## 연결이 끊어진 경우

브리지가 재시작되거나 AI가 브리지에서 연결이 끊어진 경우, 프롬프트를 다시 복사하여 붙여넣으세요. AI가 즉시 재연결됩니다. 바탕화면의 모든 기억은 연결 상태와 관계없이 보존됩니다.

---

## 매번 새 세션에서 다시 복사

새로운 AI 세션을 시작할 때마다 "프롬프트 복사"를 다시 클릭하여 붙여넣으세요. AI가 최신 상태 정보를 가져올 수 있습니다.
