AgentLimb — 让任意 AI 终端精准控制你的浏览器

        
一个 Chrome 扩展 + 一行提示词，把 Claude Code、Codex、Cursor 这类 AI 终端变成可靠的浏览器操控者。不写代码，不付云费，越用越省。

      


      
      

        
这是什么软件

        
AgentLimb 是一个 Chrome 扩展配合本地 Bridge 的轻量方案。它把 AI 终端发出的工具调用翻译成 Chrome Debugger Protocol 指令，让 AI 直接读取 DOM、点击元素、填写表单、截图导航——像一只精确的机械手。不截图猜坐标，不依赖云服务器，不需要重新登录站点，用的就是你本机 Chrome 里已经登录的账号。

      


      
      

        
给谁用

        
用 Claude Code / Codex / Cursor 处理浏览器任务的开发者；想让 AI 做重复性网页操作（采集、填表、SaaS 操作）又不想写脚本的人；用过 Browser Use / BrowseAI 但觉得太复杂或太贵的人；需要带着本机登录态操作内网系统的团队。

      


      
      

        
三步开始使用

        
    
          
  1. 复制提示词点顶部的 📋 或空闲页上的"复制接入提示词"按钮，把提示词拷到剪贴板。
    2. 
          
  2. 粘贴给 AI 终端打开 Claude Code / Codex / Cursor，把提示词整段粘贴进去。Bridge 会在后台自动启动，无需手动运行命令。
    3. 
          
  3. 开始下发任务直接用自然语言告诉 AI 你要做什么。AI 会通过插件控制浏览器，侧边栏会实时展示每一步的进展。
    4. 
        

      


      
      

        
越用越省：肌肉记忆

        
第一次访问一个网站，AI 探索并记住：哪个按钮在哪、表单怎么填、有什么坑。这些知识以 JSON 文件存在 ~/Desktop/AgentLimb-muscle/，下次直接读取，跳过探索。实测同一任务 Token 消耗下降约 85%，完成时间从几分钟压缩到几十秒。

      


      
      

        
多浏览器账号同时工作

        
在同一台电脑开第二个（或更多）Chrome Profile，AI 就能同时操纵多个账号。监控面板顶部显示该面板自己的 Profile-xxxxxx 标签；右上角状态灯三态：工作中 / 已挂起 / 未连接。点击挂起按钮可让某 Profile 暂时不响应 AI（其他 Profile 继续工作）。多个 Profile 共享同一份桌面肌肉库，知识互相复用。

      


      
      

        
支持的 AI 终端

        
Claude Code（Anthropic）· Codex（OpenAI）· Cursor · 本地部署的 Ollama / LM Studio 等任何支持工具调用的 AI 终端。同一套插件，AI 随便换。

      


      
      

        
数据与隐私

        
所有数据完全本地存储。肌肉数据保存在 ~/Desktop/AgentLimb-muscle/，你可以随时查看、备份、迁移。无遥测，无上传，不经过任何第三方服务器。

      


      
      

        
遇到问题

        
Bridge 状态红灯：点击顶部的 ⚙️ → 复制提示词重新粘贴到 AI 终端；AI 不响应：确认终端那边的工具调用功能已启用；操作不生效：点击 ⏻ 关闭 Bridge 后重新粘贴提示词重启。更多问题请到 GitHub Issues 反馈。
