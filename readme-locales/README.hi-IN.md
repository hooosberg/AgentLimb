## परिचय

**AgentLimb** एक Chrome एक्सटेंशन है जो किसी भी AI कोडिंग टूल को आपके ब्राउज़र को चलाने देता है। एक्सटेंशन इंस्टॉल करें, प्रॉम्प्ट कॉपी करें, AI में पेस्ट करें — 10 सेकंड में ऑटो-कॉन्फ़िगर।

## क्विक स्टार्ट

1. **इंस्टॉल** — [zip डाउनलोड करें](https://github.com/hooosberg/AgentLimb/releases/latest/download/agentlimb-chrome-v0.0.1.zip), अनज़िप करें, `chrome://extensions` खोलें, **Developer Mode** सक्षम करें, **Load unpacked** क्लिक करें और अनज़िप फ़ोल्डर चुनें
2. **कॉपी** — साइड पैनल खोलें, "प्रॉम्प्ट कॉपी करें" क्लिक करें
3. **पेस्ट** — किसी भी AI टूल में पेस्ट करें → ऑटो-कॉन्फ़िगर
