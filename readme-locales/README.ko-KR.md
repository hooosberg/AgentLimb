## 소개

**AgentLimb**는 모든 AI 코딩 도구(Claude Code, Cursor, Codex, Trae, Windsurf)로 브라우저를 제어할 수 있는 Chrome 확장 프로그램입니다. 확장 프로그램 설치, 프롬프트 복사, AI에 붙여넣기 — 10초 만에 자동 구성.

헤드리스 브라우저 없음. 재로그인 없음. 비침습적. 실제 Chrome, 쿠키, 세션을 그대로 사용.

## 주요 특징

| 특징 | 설명 |
|---|---|
| 원프롬프트 설정 | 프롬프트 하나만 복사 & 붙여넣기. 설정 파일 불필요 |
| 근육 기억 | AI가 한 번 탐색 → 저장 → 다음에는 제로 토큰으로 재생. ~16배 효율 |
| 제로 침입 | 기존 Chrome에서 작동. 쿠키, 로그인, 확장 프로그램 유지 |
| 100% 로컬 | Bridge는 localhost에서 실행. 분석·추적·클라우드 없음 |
| 도구 세트 | 8개의 표준화된 도구 — Unix 철학으로 최소 인터페이스, 최대 조합 가능성 |

## 빠른 시작

1. **설치** — [zip 다운로드](https://github.com/hooosberg/AgentLimb/releases/latest/download/agentlimb-chrome-v0.0.1.zip) 후 압축 해제, `chrome://extensions` 열기, **개발자 모드** 활성화, **압축해제된 항목 로드** 클릭 후 폴더 선택
2. **복사** — 사이드 패널에서 "온보드 프롬프트 복사" 클릭
3. **붙여넣기** — AI 도구에 붙여넣기 → 자동 구성 후 즉시 작동
