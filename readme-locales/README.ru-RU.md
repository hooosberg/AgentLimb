## О проекте

**AgentLimb** — расширение Chrome, [доступное в Chrome Web Store](https://chromewebstore.google.com/detail/agentlimb/hldldfepjhljhbcneojddjkkodkjglof), которое позволяет любому ИИ-терминалу — Claude Code, Cursor, Codex, Trae, Windsurf или любой локальной модели — точно управлять вашим браузером. Установите расширение, скопируйте один промпт, вставьте в ИИ — автонастройка за 10 секунд.

Без headless-браузеров. Без повторного входа. Без инвазивных агентов. Ваш настоящий Chrome, настоящие куки, настоящие сессии — плюс мышечная память, которая делает повторяющиеся задачи всё дешевле с каждым запуском.

## Ключевые возможности

### 1. Настройка одним промптом

Скопируйте один промпт, вставьте в любой ИИ-инструмент. Никаких конфигурационных файлов, никаких команд в терминале, никаких API-ключей. Если ваш ИИ может выполнять команды — он может использовать AgentLimb.

### 2. Мышечная память — 85% экономии токенов, 80–95% меньше ожидания

При первом посещении сайта ИИ исследует DOM и запоминает селекторы и рабочие процессы. AgentLimb сохраняет эти знания в `~/Desktop/AgentLimb-muscle/<domain>.json`. При каждом последующем запуске на том же сайте исследование пропускается и используется уже известное.

Реальные регрессионные данные задачи публикации на Reddit (Codex с низкими параметрами, 2026-04-18):

| | Холодный старт (первое исследование) | Горячий старт (мышечный отзыв) | Экономия |
|---|---|---|---|
| Вызовы `page_snapshot` | 3 | **0** | 100% |
| Всего вызовов инструментов | 23 | 10 | 56,5% |
| Оценка токенов | ~12 250 | **~1 750** | **↓ 85,7%** |
| Реальное время | 8–20 мин | 30 с–2 мин | **↓ ~80–95%** |

Чем чаще используется сайт, тем дешевле и быстрее становится работа.

### 3. Нативный CDP, без угадывания по скриншотам

AgentLimb управляет браузером через Chrome Debugger Protocol. ИИ получает структурированный семантический список интерактивных элементов — не скриншоты. Клики попадают в нужный узел, формы заполняются через нативные API, навигации немедленно возвращают новый URL.

### 4. Явный жизненный цикл задачи

Тишина больше не означает успех. ИИ явно объявляет `task_plan` → `task_step_done` → `task_complete` / `task_fail`. Тайм-ауты и разрывы соединения с мостом фиксируются как реальные ошибки. Боковая панель отображает список шагов в реальном времени.

### 5. 100% локально и приватно

Мост работает на `127.0.0.1:7791`. Никакой аналитики, никакой слежки, никакого облака. Мышечные знания — это простой JSON на вашем рабочем столе: читайте, сравнивайте, делитесь или удаляйте когда угодно.

### 6. Параллельное управление несколькими аккаунтами — одновременная работа с несколькими профилями Chrome

Одна команда ИИ — каждый профиль Chrome выполняет её одновременно. Два аккаунта Twitter, три корпоративных аккаунта Google или дюжина тестовых профилей——AgentLimb управляет ими всеми в одной задаче.

- **Явная идентичность** — каждая боковая панель отображает «Эта панель: Profile-xxxxxx»; Bridge знает, какой профиль вернул какой результат
- **Приостановка / авто-приостановка** — закрыть панель (или нажать «Приостановить»), чтобы исключить этот профиль из задачи; остальные продолжают без перебоев
- **Широковещание task\_\*** — `task_plan`, `task_step_done`, `task_complete`, `task_fail` транслируются каждому активному профилю; все боковые панели остаются синхронизированными
- **Блокировка окна** — `navigate` автоматически нацеливается на нужное окно Chrome, даже если один профиль открыл несколько окон
- **Маршрутизация по цели** — указывайте профиль по метке в вызове инструмента для точечного управления

## Как это работает

```
Ваш ИИ-терминал  (Claude Code / Cursor / Codex / Trae / Windsurf / локальная модель)
    ↕  HTTP + SSE  (16 стандартизированных инструментов, автообнаружение через /docs)
AgentLimb Bridge  (локальный Node.js · 127.0.0.1:7791)
    ↕  передача сообщений chrome.runtime
AgentLimb Extension  (Chrome MV3 · боковая панель · вкладки задача/мышца/лог)
    ↕  Chrome Debugger Protocol
Ваш браузер  (авторизован, с куки, настоящие сессии)
    ↓  знания сохраняются
~/Desktop/AgentLimb-muscle/<domain>.json  (постоянное хранение, читаемое человеком)
```

## Быстрый старт

1. **Установка** — два варианта:
   - **Chrome Web Store** (рекомендуется): [Установить AgentLimb](https://chromewebstore.google.com/detail/agentlimb/hldldfepjhljhbcneojddjkkodkjglof) — один клик, автоматические обновления
   - **Вручную (последняя сборка)**: [Скачайте zip](https://github.com/hooosberg/AgentLimb/releases/latest), распакуйте, откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное**
2. **Копирование** — откройте боковую панель, нажмите «Скопировать промпт»
3. **Вставка** — вставьте в любой ИИ-терминал. Он автоматически подключится, получит схему инструментов и начнёт работать

## Набор инструментов — 16 инструментов

16 стандартизированных инструментов в пяти категориях: наблюдение за состоянием браузера, навигация и взаимодействие с элементами страницы, чтение и запись мышечной памяти, объявление событий жизненного цикла задачи и поддержание связи с мостом. Полная документация предоставляется по запросу — ИИ получает схемы только тогда, когда они нужны.

## Почему просто не использовать X?

У каждого существующего подхода к автоматизации браузера есть реальная цена. Вот честное сравнение:

| | Browser Use / Playwright | BrowseAI / Browserbase | Codex / Claude Computer Use | **AgentLimb** |
|---|---|---|---|---|
| **Настройка** | Писать скрипты, управлять зависимостями, настраивать headless-режим | SaaS-конфигурация, настройка под каждый сценарий | Только Mac (нужна рабочая среда), требуется песочница | Скопируйте один промпт. Готово |
| **Выбор элементов** | CSS/XPath — вы пишете и поддерживаете их | Визуальное распознавание ИИ — нестабильно при обновлениях | Координаты скриншота — ±1 пиксель может промахнуться | CDP читает живой DOM — семантично, точно |
| **Стоимость токенов за действие** | Нет (чистый скрипт) | Плата за облако + токены ИИ | 1 000–3 000 токенов/скриншот × каждый шаг | ~300 токенов/шаг, горячий старт: на **85,7 % меньше** |
| **Стоимость повторных задач** | Фиксированная (скрипт перезапускается) | Линейно — оплата за каждый запуск | Линейно — исследует заново каждый раз, без памяти | **Снижается** — мышечная память накапливается |
| **Сессии входа** | Дополнительная настройка cookie/сессий | Облако — локальные сессии недоступны | На уровне ОС — не знает о состоянии браузера | Ваш настоящий Chrome — уже авторизованы |
| **Когда сайт обновляется** | Селекторы ломаются — переписывать скрипты | Визуальная модель может незаметно деградировать | Скриншот-инференс подстраивается, но дорого | ИИ замечает расхождение, находит новый селектор, сам чинит мышцу |
| **Конфиденциальность данных** | Локально ✅ | Через сторонние серверы ❌ | Локально ✅ | 100% локально — только 127.0.0.1 ✅ |
| **Выбор ИИ-терминала** | Любой (чистый скрипт) | Зависит от платформы | В комплекте с Codex / Claude | Любой ИИ, говорящий по HTTP |
| **Общие знания** | Скрипт = привязан к одному ИИ | Сценарий = привязан к платформе | Без постоянной памяти | Файлы мышц = между ИИ, переносимы, навсегда |
| **Параллельно мульти-аккаунт** | Ручная оркестровка | Зависит от платформы | Нет | ✅ Несколько профилей Chrome, одна команда |

**Главное отличие**: файлы мышц AgentLimb лежат в `~/Desktop/AgentLimb-muscle/` в виде обычного JSON. Знания, которые Claude Code исследовал сегодня, завтра доступны Codex — те же файлы, ноль повторных исследований. Меняйте ИИ-инструменты, не теряя ни одного уже изученного сценария.

## Варианты использования

- **Маркетинг** — Публикации в социальных сетях, управление кампаниями на разных платформах
- **Исследования** — Парсинг данных, сравнение продуктов, сбор конкурентной аналитики
- **Автоматизация** — Заполнение форм, подача заявок, обновление профилей
- **Тестирование** — QA веб-приложения в настоящем браузере с настоящими сессиями

## Философия дизайна

- **Минимальный интерфейс** — 16 инструментов, каждый делает одно дело хорошо, компонуемы в любом рабочем процессе
- **Ненавязчивость** — работает внутри вашего настоящего браузера, не в песочнице
- **Local-first** — конфиденциальность через архитектуру, а не через обещания
- **Независимость от ИИ** — любой инструмент, умеющий отправлять HTTP, может подключиться; никакой привязки к поставщику
