## О проекте

**AgentLimb** — расширение Chrome, позволяющее любому ИИ-инструменту управлять вашим браузером. Установите расширение, скопируйте промпт, вставьте в ИИ — автонастройка за 10 секунд.

## Быстрый старт

1. **Установите** — [скачайте zip](https://github.com/hooosberg/AgentLimb/releases/latest/download/agentlimb-chrome-v0.0.1.zip), распакуйте, откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное** и выберите папку
2. **Скопируйте** — откройте боковую панель, нажмите «Копировать промпт»
3. **Вставьте** — вставьте в любой ИИ-инструмент → автонастройка
