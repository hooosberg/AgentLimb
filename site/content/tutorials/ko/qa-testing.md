## 격리 테스트의 한계

표준 테스트 도구는 별도의 깨끗한 브라우저 환경에서 앱을 실행합니다. 자동화 파이프라인에는 유용하지만 한 종류의 버그를 놓칩니다. 로그인된 사용자, 특정 브라우저 확장 프로그램이 활성화된 상태, 또는 실제 브라우저 환경에서만 나타나는 문제입니다.

AgentLimb는 실제 Chrome에서 테스트합니다. 실제 세션에서만 나타나는 버그도 발견됩니다.

---

## 간단한 테스트 플로우

AI에게 확인할 것을 말합니다:

> *"my-app.com의 결제 플로우를 테스트해 주세요. 첫 번째 상품을 장바구니에 추가하고, 결제로 진행하고, 합계가 올바른지 확인하고, 결제 버튼이 보이는지 확인해 주세요. 이상한 점이 있으면 알려주세요."*

AI는:
- 앱으로 이동 (테스트 사용자로 이미 로그인됨)
- 플로우를 클릭하여 진행
- 각 단계가 올바르게 보이는지 확인
- 발견한 내용 보고, 예상치 못한 점 표시

사이드 패널에서 각 단계가 완료되는 것을 볼 수도 있고, 요약을 기다릴 수도 있습니다.

---

## 로그인이 필요한 기능 테스트

이것이 AgentLimb의 두드러진 강점입니다. 인증이 필요한 기능 — 계정 설정, 결제 플로우, 개인화된 대시보드, 관리 패널 — 테스트는 기존 테스트 도구에서 복잡한 설정이 필요합니다.

AgentLimb에서는 이미 로그인되어 있습니다. AI에게 직접 말합니다:

> *"staging.my-app.com에 로그인하여 결제 페이지에 올바른 구독 요금제와 갱신일이 표시되는지 확인해 주세요."*

쿠키 설정도, 테스트 계정 준비도 필요 없습니다. 바로 작동합니다.

---

## 테스트 플로우 저장 및 재사용

AI가 테스트를 성공적으로 실행한 후, AgentLimb가 사용한 탐색 패턴을 저장합니다. 다음에 같은 테스트를 실행할 때는 페이지 구조 재탐색을 건너뛰고 관련 요소로 바로 이동합니다. 리그레션 테스트가 한 문장 지시가 되어 몇 초 만에 완료됩니다.

---

## 여러 항목 동시 확인

한 세션에서 앱의 여러 부분을 테스트할 수 있습니다:

> *"my-app.com에서 세 가지를 확인해 주세요: (1) 로그인 플로우 작동 여부, (2) 대시보드가 오류 없이 로드되는지, (3) 설정 페이지에 이 계정의 올바른 이메일 주소가 표시되는지."*

AI가 목록을 하나씩 처리하고, 각 확인 결과를 보고하며, 이상해 보이는 것에 표시를 합니다.

---

## AgentLimb가 적합한 테스트

AgentLimb는 **탐색적·수동 스타일 리그레션 테스트** — 실제 사용자가 경험하는 방식이 올바른지 확인하는 테스트 — 에 가장 적합합니다.

코드 푸시마다 실행하는 완전 자동화 CI/CD 파이프라인에는 전용 테스트 프레임워크가 여전히 올바른 선택입니다. AgentLimb는 무언가를 빠르게 확인하고 싶을 때, 실제 세션으로 테스트하고 싶을 때, 또는 공식 테스트를 작성하기 전에 새 기능을 탐색할 때 사용하는 도구로 생각하세요.
