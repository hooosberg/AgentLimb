While Cursor and Windsurf compete in the GUI IDE space, a parallel movement is happening in the terminal. Aider, Cline, Roo Code, and Claude Code represent a growing category of terminal-based AI coding agents.

## Why Terminal?

Terminal-based agents offer unique advantages:

- **Speed** — no GUI overhead, instant startup
- **Composability** — pipe output to other tools, integrate with shell scripts
- **Remote-friendly** — work over SSH on any server
- **Minimal** — no Electron, no heavy IDE

## The Players

**Claude Code** — Anthropic's official CLI. Deep integration with Claude models, background agents, MCP support.

**Aider** — Open-source, works with any model (GPT, Claude, local models). Strong git integration.

**Cline** — VS Code extension but terminal-minded. Autonomous task execution with approval steps.

**Roo Code** — Fork of Cline with enhanced agentic capabilities and custom model support.

## AgentLimb's Fit

Terminal AI agents are natural partners for AgentLimb. They operate in the terminal, AgentLimb gives them a browser. The combination covers code + web — the two environments where developers spend most of their time.
