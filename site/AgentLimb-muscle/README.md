# AgentLimb 肌肉记忆库

⚠️  **请不要删除这个文件夹**

这里存储的是 AgentLimb 在帮你操作各网站时积累的"肌肉记忆"：
可靠的按钮选择器、已验证的操作流程、以及各站点的注意事项。

**为什么重要？**
- 有了这些记忆，AI 下次操作同一网站时可以直接上手，跳过重复探索
- 可节省大量 Token 和等待时间（通常可减少 60-80% 的探索步骤）
- 即使卸载重装插件，只要这个文件夹还在，所有记忆都能自动恢复

**文件说明**
- 每个 `.json` 文件对应一个网站，文件名 = 域名（例如 `x.com.json`）
- `index.json` 是自动维护的索引，记录所有网站的基本信息
- 本文件（`README.md`）为说明文件，可随意查阅

**安全说明**
- 这些文件里只存储 UI 结构知识（选择器、流程描述），不存储账号密码或隐私数据

如有问题，欢迎反馈。感谢使用 AgentLimb！
